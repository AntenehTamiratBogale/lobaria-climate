# Provenance

Source: user-supplied `lobaria_climate.zip`, reviewed alongside the published article, DOI 10.1111/1758-2229.13289. Source scripts and data were dated October 2023 in the archive.

The original R script, all eleven CSV files, and original SVG are retained byte for byte. `checksums.sha256` records these archived copies.

The portable script has only these preparation changes: line endings normalized; a bare fantaxtic URL changed to an R comment; unused library calls for ggnested, ggforce and reshape2 omitted. No statistical formulas, input values, figure aesthetics, thresholds, or contrast directions were intentionally changed. A separate runner supplies paths, an initial seed, a PDF device, and session recording. Its seed for previously unseeded operations is a new reproducibility aid, not a recovered historical seed.

The publication and supplementary DOCX/XLSX are linked through the article rather than duplicated. The PDF was used to establish study context, citation, raw-data accession, and analysis coverage.

The source archive contains no explicit standalone code/data license. A maintainer may add an appropriate license after confirming the rights and permissions for these materials. The publication's stated Creative Commons Attribution terms apply to the publication; they are not silently extended to independently supplied code.
